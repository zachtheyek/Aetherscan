# Aetherscan docs

This directory holds long-form technical documentation that supplements the project [`README.md`](../README.md). For installation, usage examples, and the full CLI reference, start there; reach for the documents below when you need the underlying detail. New to the codebase? Read [`ARCHITECTURE.md`](ARCHITECTURE.md) first — it's the map the others hang off.

Start here.                                                                                                                                                                                                                                                                                              |
